# Auspify Netflix ML Projects

A collection of Machine Learning projects completed as part of the **Machine Learning Internship at Auspify Technologies**.

## About the Project

This repository contains four Machine Learning projects built using the Netflix Movies and TV Shows dataset. The projects explore recommendation systems, classification models, and unsupervised learning techniques.

## Projects

### 1. Netflix Content Recommendation System

* Built a content-based recommendation system.
* Used TF-IDF Vectorization and Cosine Similarity.
* Generated recommendations based on content features.

### 2. Netflix Content Type Prediction

* Predicted whether a Netflix title is a Movie or TV Show.
* Used Random Forest and Logistic Regression.
* Evaluated model performance using classification metrics.

### 3. Netflix Audience Rating Classification

* Developed a multi-class classification model to predict audience ratings.
* Compared Random Forest and Logistic Regression.
* Evaluated results using accuracy and a confusion matrix.

### 4. Netflix Content Segmentation

* Applied K-Means Clustering to group Netflix content.
* Used the Elbow Method to select the number of clusters.
* Analyzed content patterns through visualizations.
